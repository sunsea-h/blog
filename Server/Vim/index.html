操作模式

普通模式

插入模式

命令 描述
i insert 插入
o other 在下一行插入
a append 追加
I 从行首插入
O 在上一行插入
A 在行尾追加
s 删除当前字符后插入
S 删除当前行后插入

命令模式

可视模式 (高亮的普通模式)

行可视模式: shift + v
块可视模式: ctrl + v 或 ctrl + q
缩进: 选择之后使用 > 或 < 进行缩进操作

文本对象

  • 单词和空格
    • w：下一个单词
    • W：下一个以空格分隔的单词
    • e：单词结尾
    • E：以空格分隔的单词结尾
    • b：上一个单词
    • B：上一个
  • 句子
    • s：下一个句子
    • S：上一个句子
  • 段落
    • p：下一个段落
    • P：上一个段落
  • 括号和引号
    • (：括号内的内容
    • {：大括号内的内容
    • [：方括号内的内容
    • "：双引号内的内容
    • '：单引号内的内容
    • <：尖括号内的内容
    • t：标签内的内容
  • 块
    • a：包含括号内容
    • i：仅选择括号内的内容
  • 行
    • j：当前行
    • J：包括当前行的内容
  • 文件
    • f：整个文件

跳转翻页

命令 描述
ctrl+f 下翻一页
ctrl+b 上翻一页
ctrl+d 下翻半页
ctrl+u 上翻半页
ctrl+e 下滚一行
ctrl+y 上滚一行
n% 跳转到百分比位置
zz 将当前行滚动到屏幕中间
zt 将当前行滚动到屏幕顶部
zb 将当前行滚动到屏幕底部

查找

命令 描述
/{pattern} 正方向 (文档头部开始) 查找（n 下一个, N 上一个）
/<the 匹配 the 开头的单词
/the> 匹配 the 结尾的单词
?{pattern} 反方向 (文档末尾开始) 查找（n 下一个, N 上一个）
ge 移动到上一个单词末尾
gg 移动到首部
f{char} 移动到下一个 {char} 所在（行）
F{char} 移动到上一个 {char} 所在（行）
t{char} 移动到下一个 {char} 所在的前一个字符
T{char} 移动到上一个 {char} 所在的后一个字符
; 重复上次字符查找命令
, 反向查找上次字符查找命令
* 查找当前光标的单词
# 查找当前光标的单词 (反方向)

替换

命令 描述
r 替换一个字符
cc 替换当前行（删除当前行；进入到插入模式）
cw 替换一个单词
gu 替换为小写
gU 替换为大写

:[addr]s/源字符串/目的字符串/[option]

  • addr: 范围
    • 全文: %, 1,
    • 指定行: 1,10
    • 当前行: .
    • 当前行到末尾: .,$
    • 替换选中内容: 可视模式省略 :s/aaa/bbb/g
  • option: 操作
    • g: 全局
    • i: 忽略大小写
    • c: 每次替换前确认

常用操作:
:%s= *$==： 将所有行尾多余的空格删除
:g/^$/d：将所有空行删除

内容移动

命令 描述
:n1,n2 write temp.c n1 到 n2 行内容写入 temp.c 文件中 (write 可简写为 w)
:4,5m6 移动行 4、5 到行 6 后

光标移动

命令 描述
0 移动到行首
w 移动到下一个单词开头
nw 移动到下 n 个单词开头
b 移动到当前单词/上一个单词开头 (字母,数字,下划线组成)
e 移动到当前单词/下一个单词末尾 (字母,数字,下划线组成)
B 移动到当前单词/上一个单词开头 (空白,标点符号分割)
E 移动到当前单词/下一个单词开头 (空白,标点符号分割)
enter 移动到下一行的非空白开头
^ 移动到行首非空字符
$ 移动到行尾非空字符
% 移动到与当前匹配的 (),{},<>等
nG 移动的第 n 行
G 移动到文件最后一行
gg 移动到首行
M 移动到屏幕中央一行
L 移动到屏幕底部一行
:n 光标进入到第 n 行
:$ 光标进入最后一行
m{mark} 设置标记（mark 只能为单个字符）
`{mark} 返回标记
:marks 列出所有标记
:delmarks {mark} 指定标记

复制粘贴

命令 描述
y 复制选择的内容
p 粘贴
ye 复制当前到单词结尾的部分,包括单词结尾符
yw 复制当前到下一个单词开头前的部分,不包括空格
yaw 复制当前光标所在的单词
yy 复制当前一行
nyy 复制当前开始的 n 行
dG 剪切光标之后所有内容
dgg 或 d1G 剪切光标之前所有内容
:35,45 y+ 复制特定行  复制 35 到 45 行
:1,2co3 拷贝行 1、2 到行 3 后
“*y 复制到系统剪贴板
“*p 从系统剪贴板粘贴

删除

命令 描述
x 删除当前字符
dw 删除当前到单词末尾的部分
daw 删除当前单词
dd 删除当前行
ndd 删除当前开始的 n 行
D 删除当前行光标之后的内容
d^ 删除当前行光标前的内容,不包含光标的字符
d$ 上茶当前行光标后的内容,包含光标的字符
:g/state/d 删除包含 state 的行
%d 删除全文
:n,md 删除 n 到 m 行

撤销和返回

命令 描述
u 回退
ctrl+r 返回

其他操作

命令 描述
ctrl+g 显示文档信息
:g/pattern/command 正对文件符合 pattern 的内容执行操作
:q 退出
:w 保存
:w 文件名 另存为
:q! 强制退出
:e! 放弃修改内容,重新加载文件
:qa 关闭所有文件 (同时打开多个文件时)
:bn 切换下个文件
:bp 切换上个文件
:sp 或 ctrl+w,s 上下分屏 (:sp ./ 选择要打开的文件或直接输入文件名)
:vsp 或 ctrl+w,v 左右分屏 (:vsp ./ 选择要打开的文件或直接输入文件名)
ctrl+w,h/j/k/l/w 切换分屏 (w 轮换)
ctrl+w,c 关闭当前分屏
ctrl+w,r/R 移动分屏位置 (r 下一个,R 上一个)
:E 目录跳转选择

vim 配置

用户配置：~/.vimrc
全局配置：/etc/vim/vimrc

命令 描述
set nu 行号
set autoindent 缩进
set tabstop=2 缩进字符数
syntax on 语法高亮
