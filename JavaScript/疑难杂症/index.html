疑难杂症

this 指向

全局调用

  • window(浏览器)
  • global (Node.js，模块作用域默认是 undefined)
    严格模式下，全局 this 为 undefined

方法调用

  • 普通函数，指向最终函数的调用者
  • 箭头函数，指向函数定义的作用域

避坑指南

  1. 避免在对象方法中使用箭头函数（除非刻意指向全局）
  2. 回调函数中的 this 陷阱（用箭头函数或 bind 固定 this）
  3. 严格模式警惕默认绑定（全局 this 变 undefined）

报错情况

解构赋值，将右边不是对象的转换为对象，在进行解构，undefined，null 不能转换为对象，所以解构会失败。
默认值只有严格等于 undefined 时才会生效。
基本数据类型（除了 null，undefined）在访问属性时会自动进行装箱（转换为对应的对象类型），不会报错，返回 undefined。
捕获 `` 动态导入模块失败报错

1px 边框问题

devicePixelRatio = 物理像素 / 独立像素
1.针对 devicePixelRatio>=2 的，可以设置 0.5px
2.边框图像（替换颜色需要替换图片，圆角可能出现模糊）
3.视口 + Rem
4.伪元素 + 变换

浮点数精度丢失

JS 中所有数字以IEEE 754 标准的 64 位双精度浮点数形式存储。

位双精度浮点数

第0位：符号位
第111位：指数部分
第1263位：小数部分（即有效数字）
有效数字第一位默认总是1，不算在52位中，1.xx…xx，52位存储xx…xx部分。
由于浮点数二进制存储是无穷的，所以运算会存在误差

转换为整数计算

局限：只适用于两位以内的浮点数计算

toFixed

局限：需要注意舍入误差

四舍六入五成双（银行家算法）

也叫4舍6入5凑偶。
当5后面存在有效数字，则舍5入1；
当5后面没有有效数字，且前面为奇数，则舍5入1；
当5后面没有有效数字，且前面位偶数，则舍5不进。
