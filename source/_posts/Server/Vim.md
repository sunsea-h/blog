## 文本对象

- 单词和空格
	- w：下一个单词
	- W：下一个以空格分隔的单词
	- e：单词结尾
	- E：以空格分隔的单词结尾
	- b：上一个单词
	- B：上一个
- 句子
	- s：下一个句子
	- S：上一个句子
- 段落
	- p：下一个段落
	- P：上一个段落
- 括号和引号
	- `(`：括号内的内容
	- `{`：大括号内的内容
	- `[`：方括号内的内容
	- `"`：双引号内的内容
	- `'`：单引号内的内容
	- `<`：尖括号内的内容
	- t：标签内的内容
- 块
	- a：包含括号内容
	- i：仅选择括号内的内容
- 行
	- j：当前行
	- J：包括当前行的内容
- 文件
	- f：整个文件

## 查找

| 命令       | 描述                                             |
| ---------- | ------------------------------------------------ |
| /{pattern} | 正方向 (文档头部开始) 查找（n 下一个, N 上一个） |
| /\<the     | 匹配 the 开头的单词                                |
| /the\>     | 匹配 the 结尾的单词                                |
| ?{pattern} | 反方向 (文档末尾开始) 查找（n 下一个, N 上一个） |
| ge         | 移动到上一个单词末尾                             |
| gg         | 移动到首部                                       |
| f{char}    | 移动到下一个 {char} 所在（行）                   |
| F{char}    | 移动到上一个 {char} 所在（行）                   |
| t{char}    | 移动到下一个 {char} 所在的前一个字符             |
| T{char}    | 移动到上一个 {char} 所在的后一个字符             |
| ;          | 重复上次字符查找命令                             |
| ,          | 反向查找上次字符查找命令                         |
| \*         | 查找当前光标的单词                               |
| \#         | 查找当前光标的单词 (反方向)                       | 

## 替换

| 命令 | 描述                                     |
| ---- | ---------------------------------------- |
| r    | 替换一个字符                             |
| cc   | 替换当前行（删除当前行；进入到插入模式） |
| cw   | 替换一个单词                             |
| gu   | 替换为小写                               |
| gU   | 替换为大写                               |

`:[addr]s/源字符串/目的字符串/[option]`
- addr: 范围
	- 全文: `%`, `1,`
	- 指定行: `1,10`
	- 当前行: `.`
	- 当前行到末尾: `.,$`
	- 替换选中内容: 可视模式省略 `:s/aaa/bbb/g`
- option: 操作
	- g: 全局
	- i: 忽略大小写
	- c: 每次替换前确认

常用操作:  
`:%s= *$==`： 将所有行尾多余的空格删除  
`:g/^$/d`：将所有空行删除
