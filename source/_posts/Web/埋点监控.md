## 职能范围

- 错误报警监控

## 使用 requestIdleCallback 的特殊场景处理

**1.页面关闭前的上报**

```js
document.addEventListener('visibilitychange', function () {
  if (document.visibilityState === 'hidden') {
    navigator.sendBeacon('/api/report', data)
  }
})
```

**2.兼容处理**

```js
window.requestIdleCallback = window.requestIdleCallback ||
  function (cb) {
      var start = Date.now();
      return setTimeout(function () {
          cb({
              didTimeout: false,
              timeRemaining: function () {
                  return Math.max(0, 50.0 - (Date.now() - start));
              }
          });
      }, 1);
  }
```

**3.超时控制策略**

```js
requestIdleCallback((deadline) => {
  if (deadline.didTimeout) {
    sendCriticalData();
  } else {
    processNormally();
  }
}, { timeout: 2000 })
```

## 最佳实践

- 分优先级处理：关键数据立即上报，普通数据批量处理
- 队列机制：积累足够数据或达到时间阈值时触发
- 混合策略：结合 rIC + 超时机制 + 降级方案
- 性能监控：记录上报任务执行耗时
- 错误重试：对失败请求进行指数退避重试

## 实践代码

```js
class BatchReporter {
  constructor() {
    this.queue = [];
    this.TIMEOUT = 2000;
  }

  add(event) {
    this.queue.push(event);
    if (this.queue.length >= 20) {
      this.scheduleReport();
    }
  }

  scheduleReport() {
    if ('requestIdleCallback' in window) {
      window.requestIdleCallback(
        (deadline) => this.flush(deadline),
        { timeout: this.TIMEOUT }
      );
    } else {
      setTimeout(() => this.flush(), 500)
    }
  }

  flush(deadline) {
    while (this.queue.length && (!deadline || deadline.timeRemaining() > 5)) {
      const batch = this.queue.splice(0, 5);
      sendBatchData(batch);
    }

    if (this.queue.length) {
      this.scheduleReport();
    }
  }
}
```

```js
const reporter = {
  queue: [],
  isReporting: false,
  MAX_RETRY: 3,

  add(event) {
    this.queue.push({ ...event, retry: 0 });
    this.scheduleReport();
  },
  scheduleReport() {
    if (this.isReporting) return;

    const executeReport = (deadline) => {
      this.isReporting = true;

      while (this.queue.length > 0 && deadline.timeRemaining() > 5) {
        const events = this.queue.shift(0, 5);
        this.send(events);
      }

      this.isReporting = false;
      if (this.queue.length > 0) {
        this.scheduleReport();
      }
    }

    if ('requestIdleCallback' in window) {
      window.requestIdleCallback(executeReport);
    } else {
      setTimeout(executeReport, 500);
    }
  },
  async send(batch) {
    try {
      fetch('/api/report', {
        method: 'POST',
        body: JSON.stringify(batch),
        keepalive: true
      })
    } catch (error) {
      batch.forEach(event => {
        if (event.retry < this.MAX_RETRY) {
          event.retry++;
          this.queue.unshift(event);
        }
      })
    }
  }
}
```
