# 性能优化

## 性能指标

|指标|全称|关注点|优化方向|
|---|---|---|---|
|DCL|DOMContentLoaded|DOM 解析完成时间|减少阻塞渲染的 JavaScript/CSS|
|FCP|First Contentful Paint|首次内容渲染|优化关键资源加载、压缩 CSS/JS|
|LCP|Largest Contentful Paint|最大内容渲染完成|优化图片、字体加载，提升服务器响应|
|NAV|Navigation Timing|整个页面导航过程的详细时间节点|减少 TTFB、DNS 查询、CDN 加速等|

### DCL (DOMContentLoaded)

当浏览器**完成解析初始 HTML 文档**（DOM 树构建完成）时触发，此时无需等待样式表、图片或子框架的加载。

### FCP (First Contentful Paint)

**浏览器首次渲染出任何文本、图片或非空白 Canvas/SVG 内容**的时间点。

### LCP (Largest Contentful Paint)

**视窗内最大可见内容元素（如文本块、图片、视频）完成渲染**的时间点。

### NAV (Navigation Timing)

通过 `PerformanceNavigationTiming` API 记录的**页面导航全过程的时间节点**，包括 DNS 查询、TCP 连接、请求响应等阶段。

### CLS (Cumulative Layout Shift)

累计布局偏移  
衡量页面在**加载过程中发生意外布局偏移的频率和程度**。  
例如，图片或广告突然加载导致页面内容向下跳动，或动态插入的元素破坏原有布局。
