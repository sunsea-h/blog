# 项目环境

## 目录

[项目目录](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/start-with-ets-stage)
- AppScope：整个 App 的配置，打包时使用
- entry：项目中的模块
	- main：业务代码
		- ets：页面，组件，路由
		- resources：项目资源文件
- oh_modules：依赖文件夹

## 国际化

resource 目录下，限定词文件中配置。
- base
	- element，元素资源
		- boolean，布尔型
		- color，颜色 float，浮点型，范围是 -2^128 - 2^128
		- intarray，整型数组
		- integer，整型，范围是 -2^31-2^31-1
		- plural，复数形式
		- strarray，字符串数组
		- string，字符串
	- media，图片、音频、视频等多媒体资源
	- graphic，矢量图形资源（XML 格式）
	- layout，界面布局文件（XML 格式）
	- animation，动画资源（XML 格式）
	- profile，配置文件（JSON 或 XML 格式的通用配置）
	- font，字体文件
- drak
- light
- en_US
