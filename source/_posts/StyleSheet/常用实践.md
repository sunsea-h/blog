# 常用实践

## 布局

圣杯布局, 双飞翼布局 (一般用于 PC 端)  
目的:
1. 两侧内容宽度固定, 中间内容宽度自适应
2. 三栏布局, 中间一栏最先加载, 渲染出来 (主要内容)  

实现方法: float + margin

### 圣杯布局

```html
<style>
.grail {  
  .header {  
    background-color: greenyellow;  
  }  
  
  .content {  
    padding-left: 300px;  
    padding-right: 200px;  
  
    .center {  
      background-color: palevioletred;  
      width: 100%;  
    }  
  
    .left {  
      background-color: cadetblue;  
      width: 300px;  
      margin-left: -100%;  
      position: relative;  
      right: 300px;  
    }  
  
    .right {  
      background-color: yellow;  
      width: 200px;  
      margin-right: -200px;  
    }  
  }  
  
  .footer {  
    background-color: greenyellow;  
    clear: both;  
  }  
}
</style>
<div class="layout grail">  
  <div class="header">header</div>  
  <div class="content">  
    <div class="center column">center</div>  
    <div class="left column">left</div>  
    <div class="right column">right</div>  
  </div>  <div class="footer">footer</div>  
</div>
```

### 双飞翼布局

<style>
.wings {

## 垂直水平居中

### 绝对布局

**方法一**

```css
.parent{
  width: 100px;
  height: 100px;
  position:relative;
}

.child{
  position:absolute;
  top: 50%;
  left: 50%;
  transform: translate(-50%, -50%);
}
```

**方法二**

```css
.parent{
  width: 100px;
  height: 100px;
  position:relative;
}

.child{
  position:absolute;  
  top: calc(50% - 100px);  
  left: calc(50% - 100px);
}
```

**方法三**

```css
.parent{
  width: 100px;
  height: 100px;
  position:relative;
}

.child{
  position:absolute;
  top: 50%; left: 50%;
  margin-top: -50px;
  margin-left: -50px;
}
```

**方法四**

```css
.parent{
  width: 100px;
  height: 100px;
  position:relative;
}

.child{
  position:absolute;
  top: 0; 
  bottom: 0; 
  left: 0; 
  right: 0;  
  margin: auto;
}
```

### 行高

```css
.parent{  
  width: 100px;  
  line-height: 500px;  
  text-align: center;  
}  
  
.child{  
  display: inline-block;  
  vertical-align: middle;  
  line-height: initial;  
}
```

### table 布局

```css
.parent{
  width: 100px;
  height: 100px;
  display: table-cell;
  text-align: center;
  vertical-align: middle;
}

.child{
  display: inline-block;
}
```

### Flex 布局

**方法一**

```css
.parent{
  width: 100px;
  height: 100px;
  display: flex;
}

.child{
  margin: auto;
}
```

**方法二**

```css
.parent {  
  width: 100px;  
  height: 100px;  
  display: flex;  
  justify-content: center;  
	align-items: center;  
}  
```

### Grid 布局

**方法一**

```css
.parent{
  width: 100px;
  height: 100px;
  display: grid;
  align-items: center;  
  justify-content: center;
}
```

方法二

```css
.parent{
  width: 100px;
  height: 100px;
  display: grid;
}

.child{
  align-self: center;
  justify-self: center;
}
```
