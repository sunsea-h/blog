# 小程序开发

## 微信小程序

### 注事事项

1. 自定义组件中样式不允许使用 id，属性，标签选择器，建议使用 class。
2. 子选择器只能用于 view 和 子组件，其他情况可能失效。
3. 可继承样式，会从组件外继承。
4. 全局样式、组件所在页面的样式都对自定义组件无效。
5. 在全局样式、父级页面使用标签选择器设置样式（不推荐）。
