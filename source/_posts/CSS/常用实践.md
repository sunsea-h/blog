# 常用实践

## 布局

圣杯布局, 双飞翼布局 (一般用于 PC 端)  
目的:
1. 两侧内容宽度固定, 中间内容宽度自适应
2. 三栏布局, 中间一栏最先加载, 渲染出来 (主要内容)  

实现方法: float + margin

### 圣杯布局

```html
<style>
.grail {  
  .header {  
    background-color: greenyellow;  
  }  
  
  .content {  
    padding-left: 300px;  
    padding-right: 200px;  
  
    .center {  
      background-color: palevioletred;  
      width: 100%;  
    }  
  
    .left {  
      background-color: cadetblue;  
      width: 300px;  
      margin-left: -100%;  
      position: relative;  
      right: 300px;  
    }  
  
    .right {  
      background-color: yellow;  
      width: 200px;  
      margin-right: -200px;  
    }  
  }  
  
  .footer {  
    background-color: greenyellow;  
    clear: both;  
  }  
}
</style>
<div class="layout grail">  
  <div class="header">header</div>  
  <div class="content">  
    <div class="center column">center</div>  
    <div class="left column">left</div>  
    <div class="right column">right</div>  
  </div>  <div class="footer">footer</div>  
</div>
```

### 双飞翼布局

```html
<style>
.wings {  
  .main {  
    background-color: #ddd;  
    width: 100%;  
  
    .main-wrapper {  
      margin-left: 100px;  
      margin-right: 100px;  
    }  
  }  
  
  .left {  
    background-color: orange;  
    width: 100px;  
    margin-left: -100%;  
  }  
  
  .right {  
    background-color: greenyellow;  
    width: 100px;  
    margin-left: -100px;  
  }  
}
</style>
<div class="layout wings">  
  <div class="main column">  
    <div class="main-wrapper">main</div>  
  </div>  <div class="left column">left</div>  
  <div class="right column">right</div>  
</div>
```
