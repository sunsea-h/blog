# PostCSS

## 作用

1. 将 CSS 解析成抽象语法树 (AST)
2. 交由插件处理

## 常用插件

1. Autoprefixer：自动添加 CSS 前缀以确保跨浏览器兼容性。
2. PostCSS Preset Env：根据目标浏览器或运行时环境自动应用所需的插件。
3. CSSnano：用于压缩和优化 CSS 代码。
4. PostCSS Import：用于在 CSS 中导入其他 CSS 文件。
5. PostCSS Nested：允许在 CSS 中使用嵌套规则。
6. PostCSS Mixins：允许在 CSS 中使用类似函数的混合器。
7. PostCSS Color Function：提供更多颜色处理功能，如颜色调整和转换。
