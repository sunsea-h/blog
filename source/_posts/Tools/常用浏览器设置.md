# 常用浏览器设置

## Chrome 跨域

```
"C:\Program Files\Google\Chrome\Application\chrome.exe" --disable-web-security --user-data-dir="C:/ChromeDevData"
```

## Chrome http 下获取相机权限

`chrome://flags/` 下启用 `unsafely-treat-insecure-origin-as-secure`。
