# Vue 样式研究

## 样式应用规则

- 当 style 没有设置 scope 时，声明样式为全局样式；
- 父组件的样式优先级高于子组件；
- 当子组件为单标签结构时，父子组件都有 scope 属性的话，子组件的最外层标签会同时有父子组件的 `data-v-[hash - 8]` 属性，多标签结构则不存在这个问题
  > Vue3 会在子组件外加一层 Fragment，所以单标签也不会存在该问题。

## 样式穿透

###### 普通 CSS

**Vue2**  
`.类名 >>> .类名 { 样式 }`  
**Vue3**  
`:deep(.类名) { 样式 }` 或 `::v-deep(.类名) { 样式 }`

###### Scss

在样式前加 `::v-deep`

###### Sass / Less

在样式前加 `::v-deep` 或 `/deep/`

###### 注意

- 父组件必须设置 scope
- 必须针对父元素设置样式穿透
