# 常用终端命令

```shell
# 查找最近修改的文件
ls -it | head

# 查看端口占用
lsof -i:8080

# 杀掉占用端口的进程
kill -9 $(lsof -it -i:8080)

```

位置：`~/.bashrc` 或 `~/.zshrc`

```shell
alias ll='ls -alF'
alias ..='cd ..'
alias ...='cd ../..'
```
