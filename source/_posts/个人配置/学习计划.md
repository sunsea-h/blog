# 学习计划

### 学习顺序

1. **基础阶段**：HTML → CSS → JavaScript → Git
    
2. **工程化阶段**：React → Webpack → TypeScript → 测试
    
3. **性能与安全**：性能优化 → 安全防护 → 监控工具（Sentry）
    
4. **全栈扩展**：Node.js → 数据库 → 部署（Docker/AWS）
    
5. **架构进阶**：微前端 → 设计模式 → 编译原理（Babel 插件开发）

### **阶段一：基础核心（2-3 个月）**

#### **1. HTML & 语义化**

- HTML5 标签：`<section>`, `<article>`, `<header>`, `<nav>`, `<canvas>`, `<video>`, SVG
    
- 表单增强：`<input>` 类型（email/tel/date）、表单验证（pattern 属性）
    
- SEO 优化：`<meta>` 标签、结构化数据（JSON-LD/Schema.org）
    
- 无障碍（A11y）：ARIA 角色（role）、`aria-label`、键盘导航

#### **2. CSS 深度掌握**

- **布局系统**：
    
    - Flexbox：容器属性（flex-direction/justify-content）、子项属性（flex-grow/flex-shrink）
        
    - CSS Grid：网格模板（grid-template-columns）、间距（gap）、网格线命名
        
    - 传统布局：浮动清除（clearfix）、定位（position: sticky）
        
- **响应式设计**：
    
    - 媒体查询（@media）：断点设计（移动优先）、设备像素比（-webkit-min-device-pixel-ratio）
        
    - 视口单位（vw/vh）、calc() 函数
        
- **现代特性**：
    
    - CSS 变量（--var）、自定义属性
        
    - 动画：@keyframes、transition（贝塞尔曲线）
        
    - CSS Modules、BEM 命名规范

#### **3. JavaScript 基础到进阶**

- **核心语法**：
    
    - 作用域链、闭包、IIFE（立即执行函数）
        
    - 原型链、`new` 关键字实现原理
        
    - ES6+：箭头函数、解构赋值、模板字符串
        
- **异步编程**：
    
    - Promise 链式调用（.then/.catch）、Promise.all/Promise.race
        
    - Async/Await 错误处理（try/catch）
        
    - Event Loop（宏任务/微任务）
        
- **DOM 操作**：
    
    - 事件委托（event delegation）、事件冒泡与捕获
        
    - MutationObserver、IntersectionObserver
        
    - 性能优化：防抖（debounce）、节流（throttle）

---

### **阶段二：工程化与工具链（1-2 个月）**

#### **1. 前端框架（React 为例）**

- **核心概念**：
    
    - 组件生命周期（类组件）→ Hooks（useState/useEffect/useContext）
        
    - 虚拟 DOM 与 Diff 算法、React Fiber 架构
        
- **状态管理**：
    
    - Redux：Action/Reducer/Store、中间件（redux-thunk/redux-saga）
        
    - Context API + useReducer
        
- **路由**：React Router（动态路由、嵌套路由）
    
- **SSR**：Next.js（getServerSideProps、静态生成）

#### **2. 构建工具**

- **Webpack**：
    
    - 配置 Loader（babel-loader/css-loader）、Plugin（HtmlWebpackPlugin）
        
    - 代码分割（SplitChunksPlugin）、Tree Shaking
        
- **Vite**：ESM 原生支持、热模块替换（HMR）
    
- **Babel**：预设（@babel/preset-env）、polyfill 策略

#### **3. 包管理与协作**

- npm/yarn/pnpm：依赖版本锁定（package-lock.json）、workspaces
    
- Monorepo：Lerna、Turborepo

---

### **阶段三：性能优化与安全（1 个月）**

#### **1. 性能优化**

- **加载优化**：
    
    - 资源压缩（Brotli）、HTTP/2 Server Push
        
    - 预加载（preload）、预连接（preconnect）
        
- **渲染优化**：
    
    - 减少重绘（repaint）与回流（reflow）
        
    - 使用 `will-change`、CSS 硬件加速
        
- **代码优化**：
    
    - 代码分割（React.lazy + Suspense）
        
    - 长列表虚拟化（react-window）

#### **2. 安全防护**

- XSS 防御：转义用户输入、CSP（Content Security Policy）
    
- CSRF 防护：SameSite Cookie、Token 验证
    
- HTTPS 配置：HSTS、证书管理

---

### **阶段四：全栈与架构（2-3 个月）**

#### **1. Node.js 后端基础**

- Express/Koa：中间件机制、路由分层
    
- RESTful API 设计：状态码（401/429）、HATEOAS
    
- 数据库：MongoDB（Mongoose）、PostgreSQL（Sequelize）

#### **2. TypeScript**

- 类型系统：泛型、联合类型、类型守卫
    
- 工程配置：tsconfig.json、声明文件（.d.ts）
    
- 与 React 集成：FC 类型、Hooks 类型定义

#### **3. 测试与质量**

- 单元测试：Jest（快照测试、mock 函数）
    
- E2E 测试：Cypress（断言链、网络拦截）
    
- 静态分析：ESLint（自定义规则）、Prettier

---

### **阶段五：前沿技术与架构（持续学习）**

#### **1. 跨平台开发**

- React Native：Flex 布局、原生模块桥接
    
- Electron：主进程与渲染进程通信

#### **2. 微前端与模块化**

- 方案对比：Module Federation（Webpack 5）、Single-SPA
    
- 状态隔离：Shadow DOM、CSS 作用域

#### **3. 低代码与可视化**

- 拖拽库：react-dnd
    
- 数据可视化：D3.js（力导向图）、ECharts
