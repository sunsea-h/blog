代理

在开发中可以解决跨域问题。

将 /api 前缀的请求，代理到 http://jsonplaceholder.typicode.com/，替换请求地址中的 /api 为 ''，并且将请求来源修改为目标 url。
如请求 /api/a，实际上是请求 http://jsonplaceholder.typicode.com/a。
