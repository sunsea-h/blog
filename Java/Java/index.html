Java

文件名

  1. class 带有 public 时, 类名必须与文件名相同
  2. 一个文件中只能有一个 public 类

类型

类型转换

基本类型由小到大:
byte, short, char -> int -> long -> float -> double
自动类型转换: 小转大
强制类型转换: 小类型 = (小类型) 大类型

note

  1. 一个整数赋值给 byte, short 时, jvm会自动转换
  2. 有变量参与时, byte, short 会自动提升为 int, 需要手动强转
    byte b = 1;
    b = (byte)(b+1);
  3. char 类型会自动提升为 int

内存

  1. 栈
    代码运行
  2. 堆
    保存对象, 数组
  3. 方法区
    代码的预备区, 记录类的信息以及方法的信息; 代码运行之前需要先进去内存 ( 方法区 )
  4. 本地方法栈
    专门运行 native 方法 ( C 语言编写的功能, IO 操作 )
  5. 寄存器

变量

成员变量和局部变量

成员变量 局部变量
定义位置 类方法外 方法之中或参数位置
初始化值 有，自动使用默认值（0, false, null, ‘’） 无，必须主动初始化

  3. 执行 main 方法
  4. 调用静态成员

继承

重写

注意事项

  1. 子类重写父类, 权限必须大于等于父类
    public -> protected -> 默认 -> private
  2. 私有, 静态, 构造方法不能被重写
  3. 重写方法参数, 名称相同; 返回值类型是父类型的子类型

接口和抽象类的区别

相同点:

  1. 都位于继承体系的顶端, 用于被其他类实现或继承
  2. 都不能 new
  3. 都包含抽象方法, 其子类或实现类必须重写这些抽象方法

不同点:

  1. 抽象类: 一般作为父类使用, 可以有成员变量, 构造, 成员方法, 抽象方法等
  2. 接口: 成员单一, 一般抽取都是方法, 为功能的大集合
  3. 类不能多继承, 接口可以

多态

前提

  1. 必须有接口实现或类继承
  2. 必须有方法的重写 ( 多态主要为重写方法 )
  3. new 对象: 父类引用指向子类对象

优缺点

好处: 扩展性强
坏处: 不能直接调用子类的特有功能

转型

向上转型: 父类引用指向子类对象
向下转型: 父强转子

存在问题: 类型转换异常 ClassCastException
解决: instanceof 判断类型

异常 Exception

异常分类:

  1. 编译时期异常
    Exception 以及子类, 不包括 RuntimeException 及子类
  2. 运行时期异常
    RuntimeException 及子类

抛异常注意事项:

  1. 如果父类方法抛了异常, 重写子类方法可以不抛
  2. 如果父类方法没有抛异常, 子类重写不要抛异常
